    COMPONENT 2 · CAPABILITIES & BENCHMARKS
    Conflict Resolution Pipeline & Evaluation
    How C2 arbitrates conflicting claims across structured providers and conversational memory, and benchmark comparisons across 7 arbitration methods.
    

    

    PHASE 01Source Normalization
    Ingests reports from heterogeneous providers, normalizing datetimes, currency, floats.
    
→

    PHASE 02Candidate Grouping
    Equivalent normalized values combine into candidate values with distinct source support counts.
    
→

    PHASE 03Feature Vectors
    Computes agreement share, historical provider reliability, unfamiliar-source fraction, entropy.
    
→

    PHASE 04Learned Ranking
    LightGBM listwise/pairwise model ranks candidate utilities; abstains on ties or unfamiliar sets.
    
→

    PHASE 05Memory Handoff
    Binds selected candidate to exact claim IDs; commits ACTIVE, SUPERSEDED, or CONTESTED state.
