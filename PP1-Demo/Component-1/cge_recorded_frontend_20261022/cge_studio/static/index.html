    UNIFIED CONVERSATION GOVERNANCE
    
      
    Obligation Monitoring (C1) + Belief Tracking (C3)
    
      
    How the two components fit together in the complete Conversation Governance Engine.
    
    
    
  
    
  
    
    
    
      COMPONENT 1
      Obligation Monitor (Rules & Governance)
      
    Monitors what the assistant must or must not do based on system instructions. Extracts binding rules, predicts pre-answer risk using conversation state, checks answer compliance, and maintains an obligation ledger.
    
    
    
    
    
      COMPONENT 3
      The Memory (Beliefs & Ground Truth)
      
    Monitors what the assistant commits to as true across dialogue turns and software repository steps. Builds fact dependency graphs, pinpoints dead facts upon refutation, traces shear fronts, and scores triage repair likelihood.
