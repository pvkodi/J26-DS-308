# 📝 Academic & System Documentation

This folder contains all research documentation, academic paper drafts, system architecture plans, and user manuals.

## 📂 Folder Structure

```
doc/
├── references/        # BibTeX files, reference PDFs, and citation lists
├── papers/            # Drafts and source files for the final report/paper (LaTeX or Markdown)
├── architecture/      # Diagrams, system flowcharts, database schemas, and design docs
└── guides/            # User guides, API documentation, and developer setup instructions
```

## ✍️ Best Practices

1. **Format**: Write technical reports and internal design documents in Markdown. For formal academic papers, use LaTeX (kept inside the `papers/` subfolder).
2. **Assets**: Store diagram sources (e.g., Draw.io, Mermaid, OmniGraffle) along with exported SVG/PNG representations inside `architecture/`.
3. **Citations**: Maintain a central `references/citations.bib` file for tracking academic sources.
