# 🚀 Interactive Demo Application

This folder contains user interfaces, scripting playgrounds, and web apps designed to present the research findings and core features of the **J26-DS-308** application in an interactive manner.

## 📂 Proposed Structure

```
demo/
├── client/            # Web frontend codebase (React, Next.js, or HTML/JS)
├── notebooks/         # Jupyter Notebooks demonstrating usage and step-by-step algorithms
├── scripts/           # Command-line interface (CLI) scripts for quick testing and runs
└── README.md          # Guide on launching the demo interface
```

## ⚙️ Running the Demos

### 1. Interactive Notebooks
Start the Jupyter Notebook environment to trace the research pipeline:
```bash
jupyter notebook notebooks/
```

### 2. Command Line Demos
Run quick-start demo scripts:
```bash
python scripts/run_sample.py
```

### 3. Web Dashboard (if applicable)
Navigate to the web client folder and run standard development setup commands:
```bash
cd client
npm install
npm run dev
```
Refer to the `client/` subdirectory for visual customisation instructions.
